# 🌟 Planora — Your Daily Task Planner

**Planora** is a task management web application designed to help you organize your daily activities, manage tasks, and track your progress in one place.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 View and manage your task list
- 📊 Track total and completed tasks
- 💾 Store task data using SQLite
- 🎨 Modern and colorful user interface

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js
- SQLite

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### 1. Clone the Repository

```bash
git clone https://github.com/AbhijeetKrMishra2/Planora.git
cd Planora
```

### 2. Start the Backend

Open a terminal:

```bash
cd backend
npm install
node server.js
```

### 3. Start the Frontend

Open a second terminal from the project root:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed by Vite in your browser.

## 🌐 Deployment

Planora can be deployed by hosting the frontend and backend separately. The frontend can be hosted on Netlify or Vercel, while the backend can be hosted on Render with appropriate database persistence.
